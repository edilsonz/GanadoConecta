# Trazabilidad de atributos de calidad del Sprint 1

Se mantienen los estímulos, condiciones, respuestas y medidas aprobados. La
tabla enlaza el escenario original con el componente y la evidencia disponible.
La carga progresiva hasta 2.000 usuarios virtuales es un requisito del Sprint 2.
Se medirá aparte del umbral de aceptación de EC01. [Escenarios originales](../01-analisis-de-sistema/08-escenarios-de-calidad.md) · [Atributos](../01-analisis-de-sistema/04-atributos-de-calidad.md) · [ADR](../01-analisis-de-sistema/07-decisiones-arquitectonicas.md)
