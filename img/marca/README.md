# Identidad de GanadoConecta

El [logo aprobado](ganadoconecta-logo.png) conserva los bytes del archivo
aportado `GanadoConecta-logo-aprobado.png`. La marca representa un perfil
vacuno, montañas, surcos y nodos. El lema es «Tu ganadería, siempre conectada».

La aplicación usa [variantes rasterizadas](../../frontend/src/assets/marca/).
La cabecera conserva el dibujo y el nombre. Las pantallas de acceso usan el
símbolo sin texto, ya que el encabezado identifica el sitio. El favicon de
32 px recorta el perfil y un nodo del logo aprobado. Los [iconos PWA](../../frontend/public/icons/)
de 192 y 512 px conservan el símbolo completo. La variante enmascarable
mantiene el dibujo en el área segura central.
