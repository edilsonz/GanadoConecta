# Plan — SPEC-11

Adaptador de lectura transversal con contrato de aplicación y autorización vigente por ganadería. Una consulta SQL reúne agregados y la serie acotada en una sola instantánea. Reutiliza los esquemas e índices existentes, sin migración. React usa una vista, cliente HTTP y presentación accesible. Pruebas dirigidas con PostgreSQL aislado, Vitest y navegador.
